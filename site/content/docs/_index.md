## The books

- [The Kervan framework](/docs/framework/): write MCP servers as a `kervan.yaml` spec or in
  TypeScript, serve them over stdio or Streamable HTTP, and test them. Start with the
  [quickstart](/docs/framework/quickstart/).
- [Kervan Studio](/docs/studio/): the optional self-hosted web app for teams. It edits, publishes
  and serves specs through one gateway, with users, an encrypted secret vault and an audit log.

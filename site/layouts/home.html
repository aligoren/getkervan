Why Kervan

  • Safe by default

    Spec tools reach public addresses only, keep secrets out of results, errors and logs, and every call has a timeout.

  • YAML or TypeScript

    Describe HTTP tools in YAML, or write them in TypeScript on the official MCP SDK; both get the same checks.

  • Current MCP

    Speaks the stateless MCP 2026-07-28 revision, and serves clients of the 2025 revisions from the same app.

Kervan Studio, optional

A self-hosted web UI to manage servers, secrets, users and logs. The framework works without it.

MCP servers in TypeScript, with security built in.

Kervan is a thin layer over the official Model Context Protocol SDK. Write tools in code, or declare HTTP tools in a kervan.yaml file. Validation, timeouts, error masking, transports and change notifications are handled for you.

What you get

Tools in code

Zod input schemas, typed handlers, middleware, stdio and Streamable HTTP, and a fetch handler for Workers, Deno and Bun.

Tools in a spec

kervan.yaml turns HTTP APIs into tools: templated requests, JMESPath output selection, secrets bound to hosts.

Safe defaults

SSRF protection with pinned DNS, secret redaction everywhere, size and time limits, rate limits, local-only binding.

Kervan Studio

In development: an optional self-hosted app to write, try, publish and serve specs, with an encrypted secret vault and API keys.

Get started Coming soon

Kervan is not published yet: the packages are not on npm and the source is not public. These commands will work once they are. 

npm create kervan@latest my-server
cd my-server
npm run dev

Or describe tools in a spec and run it:

specVersion: 1
name: weather
version: 0.1.0
tools:
  - name: get_daily_forecast
    description: Temperatures for the next 3 days at a coordinate.
    input:
      type: object
      properties:
        latitude: { type: number }
        longitude: { type: number }
      required: [latitude, longitude]
    http:
      url: https://api.open-meteo.com/v1/forecast
      query:
        latitude: "{{input.latitude}}"
        longitude: "{{input.longitude}}"
        daily: temperature_2m_min,temperature_2m_max
    output:
      select: "daily"
npx kervan run kervan.yaml

The editor schema for kervan.yaml is at /schema/v1.json. It will also ship in the @kervan/spec-runtime package, which validates specs offline.

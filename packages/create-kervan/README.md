# create-kervan

```sh
npm create kervan@latest my-server
pnpm create kervan my-server
```

Runs `kervan create` from the [`kervan`](https://www.npmjs.com/package/kervan) package. All of its options work here too, e.g.
`npm create kervan@latest my-server -- --no-install`.

Documentation: [getkervan.dev/docs/framework](https://getkervan.dev/docs/framework/) (start with the
[quickstart](https://getkervan.dev/docs/framework/quickstart/)).
